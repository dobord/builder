# Encrypted three-repository release builder

Public automation only. Never commit source archives, credentials, private keysets, plaintext build logs, or private SDKs here.

The release pipeline is fail-closed and remains disabled until `RELEASE_ENABLED=true` and all required credentials, public-key fingerprints, and approved commit variables have been configured.

Implementation and operating instructions are being installed as part of the encrypted release pipeline. Test workflows use synthetic public data only.
